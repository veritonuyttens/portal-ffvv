# Portal FFVV · app para celular

Acceso directo instalable (PWA) al Portal Integral FFVV. Esta página solo muestra la pantalla de instalación y el ícono; el portal y sus datos están en Google Apps Script (ingreso con carnet y PIN). En el celular no se guarda ningún dato del portal.

- Dirección para instalar: https://veritonuyttens.github.io/portal-ffvv/
- Android (Chrome): botón **Instalar en este celular** o menú ⋮ → **Instalar app**.
- iPhone (Safari): **Compartir** → **Agregar a inicio**.
- El enlace del portal se configura en `index.html` (`PORTAL_URL`).
